# DZS Commission Bot V4
Features:
- Skin 64 / 128 / 512
- Render, Logo, Animasi
- Automatic DZS-0001 numbering
- Private commission tickets
- Worker claim and ticket status
- 1-5 star feedback
- Feedback shows Worker, Reviewer, Rating and Review/Ulasan
- Railway-ready

Set the variables from .env.example in Railway.
For SQLite persistence on Railway, mount a Volume at /app/data.
